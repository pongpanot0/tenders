Danger#dc2626

Typography & Iconography

  • Display: Space Grotesk 600-700 weight (page titles, callouts)
  • Body: Inter 400-600 weight (labels, prose, tables)
  • Mono: JetBrains Mono 400-500 weight (IDs, codes, debug info)
  • Icons: Lucide icon set (outline style, 1.75–2px stroke) via CDN. Every icon-only control includes tooltip and accessible name.

Key Updates (This Iteration)

  • Icon library: All mockups now use Lucide icons (https://lucide.dev) via CDN, replacing emoji/unicode. Icons are genuinely interactive and accessible.
  • P1 screens: Added 8 full-fidelity mockups per spec section 15. Pipeline workspace context panel, tender version diff UI, saved searches, Slack config, source coverage, export jobs, admin panels (source health + review queue).
  • P2 screens: Bundled 6 lighter-fidelity sketches into one tabbed mockup for reference and roadmap planning.
  • Admin visual separation: Admin screens include explicit "Admin" label and danger-colored environment marker. Never reachable accidentally from normal navigation.
  • Deferred: Very little remains deferred—mostly deep integration flows and complex collaboration features that require backend definition (CRM sync, SSO/SCIM provisioning details, advanced analytics).

Coverage Summary

  • P0 (8 screens): Sign in, onboarding, app shell, inbox, tender detail, explore, alerts, pipeline board. All states covered (default, loading, empty, error).
  • P1 (8 screens): Pipeline workspace, version diff, saved searches, Slack config, source coverage, export jobs, admin source health, admin review queue. Full fidelity, production-ready references.
  • P2 (1 bundle file, 6 features): CRM integration, collaboration/mentions, SSO/SCIM, API keys, multi-profile comparison, learning controls. Lighter fidelity for early validation.
  • Responsive: Desktop (1280px+) primary layout. Mobile adaptations in app shell mockup. Breakpoints follow spec section 9.

Handoff Notes for Engineering

  • All CSS uses design tokens (--color-*, --space-*, --radius-*). Never use raw colors ad hoc.
  • Replace Lucide CDN link with production-ready bundler or SVG sprite approach for performance.
  • Implement all 8 interaction states per spec section 8: default, hover, focus-visible, active, disabled, loading, error, success. Verify no layout shifts.
  • Mobile breakpoints: 320, 375, 414, 768, 1024, 1440 CSS px. Test with 200% zoom and reflow.
  • Keyboard navigation: Tab reaches all controls, Arrow keys navigate lists/tables, Escape closes modals, Enter confirms. Announce state changes via aria-live.
  • Admin screens must have explicit visual separation from customer app. Use spec section 6.10 warning language and never link from normal navigation.
  • Content rules: No invented logos/metrics/testimonials. Thai/English UI-ready. Status labels use text+icon (never color alone). Confidence and risk are separate fields.
